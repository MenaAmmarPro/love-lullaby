# Goodnight, Mena — love-lullaby

A soft place to end the day. Tonight's **moon phase** is computed from the date
(synodic month), a gentle lullaby line rotates each night, and **Goodnight**
tucks the night into a log — come back daily to keep the streak.

Live: https://menaammarpro.github.io/love-lullaby/

## Send a goodnight

`Send a goodnight` copies `?lullaby=1`. Whoever opens it sees
"**Ammar sent you a goodnight — sleep well, Mena.**" with the moon pulsing.

## Storage key

- `mena-lullaby` — `{ nights: ["YYYY-MM-DD", …], line, last }`
